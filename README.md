### What I learned

This project helped me practice building a component from a design using HTML and CSS.

I learned how to:

- Structure a webpage using semantic HTML.
- Use Flexbox to position and align elements.
- Create a responsive layout for different screen sizes.
- Use CSS custom properties.
- Add hover states to interactive elements.
- Use Google Fonts in a project.
- Pay attention to spacing, typography, colors, and sizing.

One example I practiced was using Flexbox to center the card:

```css
.background{
    width:100%;
    height:950px;
    background-color: hsl(47, 88%, 63%);
    display:flex;
    justify-content: center;
    align-items: center;
}
